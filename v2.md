# 1bOS V2

![1bOS Ring Thing Logo](logo.jpg)

The source code for the **1bOS Ring Thing** (v2).

V2 adds new apps, improved information display and a weather system that allows the Ring Thing to show real-time weather using only a Wi-Fi connection.

Feel free to open issues or submit pull requests if you want to add features, improvements, or fixes!

## Features

- Swatch Internet Time clock
- One-button navigation
- Timer app
- Weather app
- Automatic location detection
- Free weather data (no API key required)
- NeoPixel ring animations
- Low brightness mode
- Timer alarm flash
- Temperature range visualization


# Installation

Clone the repository:

```
git clone https://github.com/a9plus/1bOSV2.git
cd 1bOSV2
```

Install the required Python packages:

```
sudo pip3 install \
adafruit-blinka \
adafruit-circuitpython-neopixel \
Adafruit-Blinka-Raspberry-Pi5-Neopixel \
requests \
--break-system-packages
```

Run 1bOS:

```
sudo python3 main.py
```

If gpiod is not already installed:

```
sudo apt update
sudo apt install python3-libgpiod gpiod
```


# How to use 1bOS V2


## Clock App

When 1bOS boots, you will see green, yellow and red LEDs.

These represent the current Swatch Internet Time.

Some LEDs may overlap if multiple digits have the same value.

- Green = first digit
- Yellow = second digit
- Red = third digit


Example:

```
Swatch time: 932

Pixel 9 = Green
Pixel 3 = Yellow
Pixel 2 = Red
```


## Switching Apps

To switch between apps:

1. Hold the button for about one second.
2. Release the button.
3. 1bOS will switch to the next app.


Current apps:

- Clock
- Timer
- Weather


# Timer App

When opening the timer app, the LEDs will be blank.

Controls:

- **Single click:** Add 1 minute to the timer
- **Double click:** Start or pause the timer  
  (Two clicks within 500ms)

The blue LEDs show the remaining percentage of the timer.

When the timer finishes:

- The ring flashes white 3 times
- The timer resets back to 0


# Weather App

The Weather App displays current weather using the 10-pixel NeoPixel ring.

The app uses free weather services and does not require:

- An account
- An API key
- A subscription


## Weather Setup

When opening the Weather App:

1. 1bOS first tries to detect your location automatically using your internet connection.
2. If automatic detection fails, 1bOS asks for your location in the terminal.

Supported location methods:

```
ZIP code

or

Latitude,Longitude
```


Example:

```
18.30000, -64.82528
```


# Weather Display

The ring is divided into sections:

```
Pixel 1  - Sky condition
Pixel 2  - Weather event
Pixel 3  - Temperature range
Pixels 4-10 - Temperature meter
```


## Sky Condition

Pixel 1:

- Yellow = Sunny
- Gray = Cloudy


## Weather Event

Pixel 2:

- Blue = Rain
- Yellow = Sunny
- Orange = Storm
- White-blue = Snow
- Gray-green = Unknown/Natural event


## Temperature Display

Pixel 3 shows the temperature range:

- White = Below 0°F
- Blue = 0°F - 31°F
- Green = 32°F - 50°F
- Yellow = 51°F - 70°F
- Orange = 71°F - 90°F
- Red = 91°F - 109°F
- Purple = 110°F+


Pixels 4-10 show the approximate position inside the current temperature range.

Example:

```
45°F

Green temperature zone

🟢🟢🟢🟢🟢⬛⬛
```

Meaning:

The temperature is around 70% through the 32°F-50°F range.


# Weather Updates

The Weather App refreshes weather data every 3 minutes.

This prevents unnecessary network requests while keeping the display updated.

If the internet temporarily stops working, 1bOS keeps the previous weather data until a new update succeeds.
